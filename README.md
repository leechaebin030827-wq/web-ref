# Motion Index — Interactive Web References

단일 HTML 파일로 만든 웹 애니메이션/인터랙션 레퍼런스 인덱스입니다. 별도의 서버나 패키지 설치가 필요하지 않습니다.

## 사이트 미리보기

`index.html` 파일을 웹 브라우저에서 열면 됩니다.

## 인터넷에 공개 링크 만들기 (Netlify Drop)

1. https://app.netlify.com/drop 에 접속합니다.
2. 이 ZIP 파일을 업로드하거나 압축을 푼 폴더를 드래그하여 놓습니다.
3. Netlify가 생성한 `*.netlify.app` 주소를 공유합니다.

다른 방법: Vercel / GitHub Pages / Cloudflare Pages 등에 `index.html`을 루트에 올려도 됩니다.

## 포함 기능

- 7개 카테고리, 60개 레퍼런스
- 이름/설명/태그/도메인 검색 및 카테고리 필터
- 북마크(같은 브라우저의 로컬 저장소에 저장) 및 북마크만 보기
- 현재 필터링된 레퍼런스 링크 복사
- 라이트/다크 테마, 반응형 레이아웃
- 별도의 JS 빌드 또는 설치 과정 없음

원본 조사 텍스트를 기반으로 항목을 정리했습니다. 링크는 각 서비스에서 변경될 수 있으며, 소스코드 사용 전 해당 프로젝트의 최신 라이선스를 확인하세요.
